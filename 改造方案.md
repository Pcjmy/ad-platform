
# 广告营销系统技术栈升级改造方案

## 1. 项目概述

### 1.1 项目背景
- **当前项目**：ad-platform（Spring Boot 4.0.7 + Spring Cloud 2025.x）
- **参考项目**：imooc-ad（Spring Boot 2.0.2 + Spring Cloud Finchley）
- **目标**：将参考项目的业务功能迁移到现代化技术栈，保持功能对齐

### 1.2 技术栈对比

| 技术组件 | 当前项目 | 参考项目 | 升级说明 |
|---------|---------|---------|---------|
| Spring Boot | 4.0.7 | 2.0.2.RELEASE | 使用最新 LTS 版本 |
| Spring Cloud | 2025.1.2 | Finchley.RELEASE | 使用最新版本 |
| Spring Cloud Alibaba | 2025.1.0.0 | 无 | 新增，用于 Nacos 集成 |
| 服务网关 | Spring Cloud Gateway | Netflix Zuul | Gateway 是 Zuul 的官方替代 |
| 服务注册 | Nacos Discovery | Eureka Server | Nacos 功能更丰富 |
| 持久层 | MyBatis Plus | Spring Data JPA | MyBatis Plus 更灵活 |
| 服务容错 | Resilience4j | Hystrix | Resilience4j 是 Hystrix 的替代 |
| JSON 处理 | FastJSON2 | FastJSON | FastJSON2 更安全 |
| Java 版本 | 17 | 8 | 使用最新 LTS |

**核心代码实现：**

1. **统一响应格式** `CommonResponse<T>`：
```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class CommonResponse<T> implements Serializable {
    private Integer code;
    private String message;
    private T data;
    
    public CommonResponse(Integer code, String message) {
        this.code = code;
        this.message = message;
    }
}
```

2. **全局响应包装** `CommonResponseDataAdvice`：
```java
@RestControllerAdvice
public class CommonResponseDataAdvice implements ResponseBodyAdvice<Object> {

    @Override
    public boolean supports(MethodParameter methodParameter,
                            Class<? extends HttpMessageConverter<?>> aClass) {
        if (methodParameter.getDeclaringClass().isAnnotationPresent(IgnoreResponseAdvice.class)) {
            return false;
        }
        if (methodParameter.getMethod().isAnnotationPresent(IgnoreResponseAdvice.class)) {
            return false;
        }
        return true;
    }

    @Nullable
    @Override
    public Object beforeBodyWrite(@Nullable Object o,
                                  MethodParameter methodParameter,
                                  MediaType mediaType,
                                  Class<? extends HttpMessageConverter<?>> aClass,
                                  ServerHttpRequest serverHttpRequest,
                                  ServerHttpResponse serverHttpResponse) {
        CommonResponse<Object> response = new CommonResponse<>(0, "");
        if (null == o) {
            return response;
        } else if (o instanceof CommonResponse) {
            response = (CommonResponse<Object>) o;
        } else {
            response.setData(o);
        }
        return response;
    }
}
```

3. **全局异常处理** `GlobalExceptionAdvice`：
```java
@RestControllerAdvice
public class GlobalExceptionAdvice {

        CommonResponse<String> response = new CommonResponse<>(-1, "business error");
        response.setData(ex.getMessage());

    }
}
```

**1. 新增文件 1：`PreRequestFilter.java`（前置过滤器）**

**路径**：`src/main/java/com/adplatform/adgateway/filter/PreRequestFilter.java`

**功能**：记录请求开始时间（对应参考项目的 `PreRequestFilter`）

```java
package com.adplatform.adgateway.filter;

import lombok.extern.slf4j.Slf4j;
import org.springframework.cloud.gateway.filter.GatewayFilterChain;
import org.springframework.cloud.gateway.filter.GlobalFilter;
import org.springframework.core.Ordered;
import org.springframework.stereotype.Component;
import org.springframework.web.server.ServerWebExchange;
import reactor.core.publisher.Mono;

@Slf4j
@Component
public class PreRequestFilter implements GlobalFilter, Ordered {

    private static final String START_TIME_ATTR = "startTime";

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        exchange.getAttributes().put(START_TIME_ATTR, System.currentTimeMillis());
        return chain.filter(exchange);
    }

    @Override
    public int getOrder() {
        return Ordered.HIGHEST_PRECEDENCE;
    }
}
```

**2. 新增文件 2：`AccessLogFilter.java`（访问日志过滤器）**

**路径**：`src/main/java/com/adplatform/adgateway/filter/AccessLogFilter.java`

**功能**：记录请求 URI 和耗时（对应参考项目的 `AccessLogFilter`）

```java
package com.adplatform.adgateway.filter;

import lombok.extern.slf4j.Slf4j;
import org.springframework.cloud.gateway.filter.GatewayFilterChain;
import org.springframework.cloud.gateway.filter.GlobalFilter;
import org.springframework.core.Ordered;
import org.springframework.stereotype.Component;
import org.springframework.web.server.ServerWebExchange;
import reactor.core.publisher.Mono;

@Slf4j
@Component
public class AccessLogFilter implements GlobalFilter, Ordered {

    private static final String START_TIME_ATTR = "startTime";

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        return chain.filter(exchange).then(Mono.fromRunnable(() -&gt; {
            Long startTime = exchange.getAttribute(START_TIME_ATTR);
            if (startTime != null) {
                String uri = exchange.getRequest().getURI().getPath();
                long duration = System.currentTimeMillis() - startTime;
                log.info("uri: {}, duration: {}ms", uri, duration);
            }
        }));
    }

    @Override
    public int getOrder() {
        return Ordered.LOWEST_PRECEDENCE;
    }
}
```

## 7. 注意事项

### 7.1 兼容性问题

1. **Spring Boot 4.x 配置变更**
   - `spring.factories` 改为 `spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`
   - Jakarta EE 9+ 包名变更（`javax.*` → `jakarta.*`）

2. **MyBatis Plus 配置**
   - 使用 `mybatis-plus-spring-boot3-starter` 而非旧版本

### 7.2 迁移策略

- **分阶段迁移**：先完成核心模块，再完善功能
- **保持接口兼容**：对外 API 与参考项目保持一致
- **逐步替换 Eureka**：可先双注册，再逐步下线 Eureka

### 7.3 测试策略

- 单元测试：使用 JUnit 5
- 集成测试：使用 TestContainers
- API 测试：使用 Knife4j + Postman
